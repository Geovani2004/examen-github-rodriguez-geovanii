# Catálogo de Libros

Proyecto web básico desarrollado con HTML, CSS y un archivo de datos en formato CSV para gestionar y visualizar un listado de libros.

## Estructura del Proyecto

El repositorio contiene los siguientes archivos principales:

- `index.html`: Estructura principal y contenido visual de la página web.
- `styles.css`: Archivo de estilos encargado del diseño y la apariencia visual.
- `libros.csv`: Base de datos en formato CSV (actualmente vacía) para almacenar la información de los libros.
